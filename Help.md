| Key            | Action                                      |
|----------------|--------------------------------------------|
| R              | Restore the initial view                   |
| W, A, S, D     | Move: Forward, Backward, Left, Right       |
| ↑              | Move Camera Upward                         |
| ↓              | Move Camera Downward                       |
| →, ←           | Rotate Camera: Left, Right                 |
| ↑              | Rotate Camera Upward                       |
| ↓              | Rotate Camera Downward                     |
